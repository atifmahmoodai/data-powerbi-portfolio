## Open a report

For core projects, open `Dashboard.pbip` inside each numbered folder. For opportunity demos, open `PowerBI/Dashboard.pbip` inside the numbered subfolder. Use Power BI Desktop on Windows, refresh in Demo mode, and complete the acceptance checklist before presenting the report as client-ready.

The additional projects use generated native PBIP model/report sources; Power BI Desktop validation (opening, refresh, DAX evaluation, visuals) remains outstanding. Their companion pages are browser analytics references, not replacements for the PBIP. All data is synthetic. There are no customer system connectors, scheduled refresh, or Power BI Service publishing configurations.
